# MSLG_SPA_2026_Communicador-Innato

Para conseguir la API de gemini utilizada en este proyecto se requiere ir a Google AI Studio, importar o crear un proyecto para crear una clave de API. Una vez creada se copia y se pone en AI_system.py justo donde se indica.

El modelo usado es Gemini 3.1 Flash Lite, en la version gratuita da 500 usos por dia.

Se agregaron los datasets con los que se realizaron las pruebas.
